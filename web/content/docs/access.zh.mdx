---
title: 访问权限
description: 决定智能体能用哪些插件和工具，能不能读写文件、在它的 Runner 上运行命令。
icon: SlidersHorizontal
---

智能体的 **访问权限** 决定它的工具在 Runner 上能做什么：能用哪些插件、用到什么程度（可以细到单个工具），能不能读取或修改文件，能不能运行 shell 命令。描述告诉智能体该做什么，访问权限决定它做得了什么。新建的智能体默认是完全访问。

Lorca 会先检查访问权限，再交给[自动审查](/zh/docs/auto-review)，调用真正执行时还会再查一次。规则、**始终允许**，或者智能体自己提出的请求，都不能放宽访问权限。

## 打开访问权限

在桌面应用里，打开智能体的单聊并显示检查器。资料卡片里有一行 **访问权限**，显示 **完全访问** 或 **受限**，点它即可。在手机上，打开聊天的详细信息，轻点描述下面的 **访问权限**。

| 部分 | 你可以选 |
| --- | --- |
| **插件** | Runner 上每个插件的级别：**读取和写入**、**读取和起草**、**仅读取** 或 **无访问权限**。 |
| **工具** | 插件连接过之后，展开它可以看到每个工具的复选框，以及它做什么：读取、起草或更改。超出插件级别的工具是关闭的。 |
| **消息** | **先写草稿**：智能体写的邮件和 Slack 消息会先作为[草稿](/zh/docs/reviews#邮件和-slack-草稿)留在聊天里，由你发送。默认打开。 |
| **文件** | 智能体文件工具的权限：**读取和写入**、**仅读取** 或 **无访问权限**。 |
| **Shell 命令** | 是否允许运行命令的开关。 |

桌面应用里点 **保存** 生效；手机上每改一项就立即保存。

智能体不能用的插件不会出现在它的回合里：它看不到这个插件，检查器的插件部分也会在旁边标出 **无访问权限**。之后新装的插件，在完全访问时可以直接用；访问权限受限后，需要先给它定一个级别。智能体的[浏览器配置文件](/zh/docs/browser)属于 Browser 插件，跟随它的级别。

## 智能体需要更多权限时

智能体尝试做访问权限不允许的事时，这次调用会被拒绝，智能体会告诉你，聊天里还会出现一张卡片：写明它需要什么，比如“GitHub · create_issue”或“Shell 命令”，下面是 **编辑访问权限…** 和 **忽略**。这张卡片本身从不执行那次调用。改好访问权限后，让智能体再试一次。

## 智能体与队友

智能体不能修改自己或其他智能体的访问权限。智能体创建的队友，一开始继承创建者的访问权限。交给另一个智能体的工作，按那个智能体自己的访问权限运行；群聊里每个智能体的回合也是如此。

<Callout type="warn" title="Shell 和文件能触及整台电脑">
  Shell 命令以你的身份运行，能访问你能访问的一切，不受“文件”设置限制，包括插件自己的设置和登录信息。所以插件上的限制，只在智能体的 shell 和文件权限范围内有效：两者都关掉，智能体就只能通过插件做事。如果某个智能体绝不能碰某样东西，就给它一台只装了它所需内容的 Runner。
</Callout>
