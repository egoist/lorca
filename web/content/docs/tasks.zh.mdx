**任务** 是一次回合做不完的工作：一个目标、负责它的智能体、怎样算完成，以及下一步。它跟着负责的智能体，跨越多个回合、很长的聊天和重启，直到做完；参与其中的每个智能体都能看到它进行到哪一步。

## 新建任务

在桌面应用里，点检查器 **任务** 旁边的 **+**，或选择 **文件 › 新建任务…**。在手机上，轻点聊天详细信息里的 **新建任务**。然后填写：

| 字段 | 含义 |
| --- | --- |
| **目标** | 要做成什么。 |
| **负责人** | 由谁来做，这个聊天里的某个智能体。 |
| **下一步** | 智能体先做什么。 |
| **完成标准** | 怎样算做完，每行一条。 |

也可以直接跟智能体说：“把这个建成任务，一直跟进到迁移合并为止。”智能体自己也能创建、更新和运行任务。

## 开始做

**开始** 让负责人在这个聊天里着手这个任务。这一轮结束后，它的回复以及它[发布](/zh/docs/chats#输出)的文件和链接会作为任务的证据保存下来，任务变成 **待审阅**。只有一条回复，任务永远不会自动完成：看过结果后选 **标记为完成**，或者告诉智能体还缺什么。

回合被停止或失败时，任务会变成 **受阻**，并写明原因；**恢复** 让智能体再试一次。任务可以依赖其他任务；**开始** 会等那些任务完成后才可用。

如果智能体的电脑在运行途中重启，任务会变成受阻，并说明工作可能只做了一半。先看看发生了什么，再 **恢复**。

## 跟进

检查器的 **任务** 部分列出这个聊天的任务（手机上在聊天的详细信息里）：受阻和待审阅的排在前面，然后是正在工作、未开始和已结束的。每一行显示目标、状态，群聊里还会显示负责人。点开一个任务：

- 状态、受阻的原因，以及结果和它的证据：一条消息、某个输出的某个版本，或一个链接，都可以点开。
- 当前状态下能走的那一步：**开始**、**恢复**、**标记为完成**，或对已结束的任务 **重新打开**。**取消任务…** 会先确认。
- 目标、负责人、下一步和完成标准，可以修改后 **保存**。智能体正在做的时候，负责人和完成标准保持不变。
- 一行 **上限**，用来限制这个任务能花多少；见[上限](/zh/docs/limits)。

智能体每一步都会读到自己未完成的任务，所以长聊天被压缩也不会把任务丢掉。为某个任务[交给其他智能体](/zh/docs/chats#智能体之间互相发消息)的工作，完成后会把结果记进任务的证据。

在终端里，`lorca tasks list` 和 `lorca tasks get <id>` 可以查看任务；见[命令行](/zh/docs/cli#命令)。
