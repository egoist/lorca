---
title: 上限
description: 限制智能体的回合、任务和例行任务能花多少，以及智能体调用插件服务的频率。
icon: Gauge
---

上限让工作在花得比你预想更多之前停下来：跑得太久的回合、一直在花钱的例行任务、用掉太多 token 的任务。插件的调用上限则让智能体调用某个服务的速度不超过它允许的范围。

## 可以限制什么

| 上限 | 计算的是 |
| --- | --- |
| **花费** | 美元，按服务商公布的 API 价格计算。 |
| **Token** | 发给模型和从模型收到的 token。 |
| **运行时间** | 分钟数，包括等待模型、插件和你回答的时间。 |
| **重试** | 服务商出错后重新发送的请求数。 |
| **插件调用** | 调用插件工具的次数。 |

留空表示不限制。上限面板里，每一项旁边都会显示已经用了多少。

## 上限用在哪里

- **智能体的单聊：** 智能体检查器的 **运行方式** 下面、花费之后，有一行 **上限**（手机上在详细信息里）。这个聊天里每一个新的回合，碰到其中任何一项就会停下。别的智能体交给它的工作也算在这里。
- **任务：** 任务的面板里有一行 **上限**。任务的所有运行合起来计算；达到上限时，任务会受阻，直到你恢复它。
- **例行任务：** 例行任务面板的时间安排部分有一行 **上限**。它的所有运行和检查合起来计算；达到上限时会显示 **已达上限**，你恢复之前不会再运行。

上限保存在智能体的 Runner 上；智能体换到另一台 Runner 后，没有上限。

## 工作停下时

达到上限的回合会在下一步停下，聊天里会写明原因，比如“Stopped at the token limit. Raise it in Limits to resume.”。上限那一行会以橙色显示 **已达上限**，面板里会写明是哪一项，并提供 **恢复**。提高这项上限后选 **恢复**，工作就从停下的地方继续。不提高的话，恢复前会先问你，然后把全部上限重新给它一遍。

回合所在的电脑重启导致中断时，会显示 **已中断** 并等你处理，因为它可能已经做了一部分。重启永远不会重置上限。

## 价格

花费按服务商的 API 价格计算。ChatGPT、Grok 或 OpenCode Go 订阅下的回合，按同样的价格折算它本该花多少，检查器会把这个数字标为“约”。自定义服务商的价格未知，检查器会显示“价格未知”，花费上限会让它的回合立即停下；这种情况请改用 token 或运行时间来限制。

## 插件调用上限

一台 Runner 上的所有智能体，共用每个插件账号的调用上限：一开始是每分钟 60 次、同时 4 次。插件面板的状态部分有一行 **调用上限**，点开可以设置每隔多少秒最多 **调用** 几次，以及 **同时** 最多几次。对于有[多个账号](/zh/docs/plugins#多个账号)的服务，**适用于** 可以选只限 **这个账户**，还是这个服务的所有账号。

服务要求 Lorca 放慢速度时，这一行会显示“等待至”某个时间，之后的调用会等到那时。调用不会因此被重复发送。在手机上，插件页面可以设置这个账号的上限；整个服务的上限要在电脑上设置。
