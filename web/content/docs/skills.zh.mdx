**技能** 是为某个智能体或某个群聊写下的做事方法：什么时候用、步骤、一个示例，以及它需要的参考资料或脚本。智能体每一轮都能看到自己各个技能的名称和描述，遇到匹配的任务时才读取完整内容，所以技能写得再长，用不到时也不占地方。

## 技能在哪里

智能体的技能在它单聊检查器的 **技能** 部分，群聊的技能在群聊的检查器里（手机上在聊天的详细信息里）。有了技能或草稿之后，这个部分才会出现。群聊的技能供群里每个智能体使用，只在这个群聊里有效。

## 写一个技能

选择 **聊天 › 新建技能…**，或在 **技能** 部分出现后点它旁边的 **+**（手机上是 **添加技能 › 新建技能…**）。一个技能包括：

| 字段 | 含义 |
| --- | --- |
| **名称** | 简短的名字，写成英文短横线形式，比如 `weekly-report`。 |
| **描述** | 什么时候用它。智能体靠这段话来判断。 |
| **指令** | 具体步骤。 |
| **示例** | 好的结果长什么样。 |
| **参考资料** 和 **脚本** | 技能附带的文本文件，比如一份风格指南，或者智能体用自己的工具运行的脚本。 |

**保存** 后，智能体从下一轮开始就能用。看起来像密码或密钥的内容，保存时会被去掉。

## 从聊天里存一个

智能体某件事做得正合你意、希望以后照做时，右键点按它的回复，选择 **存为技能…**。同一件事你已经纠正过它不止一次时，右键点按你自己的某条消息，选择 **存为长期指令…**。在手机上，用详细信息里的 **添加技能 › 从这个聊天中…**。

面板会列出聊天里最近的消息：勾选能体现这项工作的那几条；在群聊里，还要选这个技能是给整个群聊用，还是只给某个智能体用。**继续** 会让智能体的服务商根据这些消息写一份草稿，打开给你修改。智能体也可以自己提议一个技能，聊天里会告诉你去哪里审阅。

草稿永远不会被使用。只有 **保存** 之后它才生效。

你还可以在智能体的浏览器里亲手做一遍某个网站上的任务，教会它；见[录制工作流程](/zh/docs/browser#录制工作流程)。

## 历史记录与导出

已保存技能的 **历史记录** 标签页列出每一个版本，附带日期和设备：已创建、根据聊天起草、已保存、已编辑。选中某个版本，就能看到它当时写了什么。技能会同步到你所有的设备。

技能菜单里的 **导出…** 会把它存成一个文件，自己留着或交给别人（手机上通过共享面板）。文件里只有技能的文字和附带文件，不包含你账号的任何信息。要连同技能分享整个智能体，见[分享智能体](/zh/docs/templates)。

智能体的[反馈](/zh/docs/feedback)可以建议修改技能的指令，由你接受或拒绝。
