任何智能体都可以作为 **模板** 分享：它的资料，加上你挑选的技能、例行任务、记忆和插件。打开模板的人会在自己的电脑上新建一个属于自己的智能体，用他自己的 AI 服务商和登录。

## 模板里有什么

| 部分 | 包含的内容 |
| --- | --- |
| **资料** | 名称、描述（也就是智能体的指令）、符号和颜色。始终包含。 |
| **技能** | 你勾选的[技能](/zh/docs/skills)。 |
| **例行任务** | 你勾选的重复性[例行任务](/zh/docs/routines)，连同时间安排和任务说明。 |
| **记忆** | 智能体[记忆](/zh/docs/memory)里的条目和主题笔记。不包括每日日志。 |
| **插件** | 智能体要配合使用的服务，比如 GitHub。不包括你的账号或登录。 |

模板里不会有你的服务商或模型、智能体所在的电脑或文件夹、它的头像图片，也不会有任何登录信息。看起来像密钥或密码的内容会被去掉。分享前值得再看一眼的条目，会在行尾标出来，比如橙色标记的邮箱地址。

## 分享

在桌面应用里，打开智能体的单聊，选择 **文件 › 作为模板分享…**，或者在侧边栏里右键点按这个聊天。在手机上，轻点聊天详细信息里的 **作为模板分享**。勾选要包含的内容，然后：

- **分享链接**：生成一个 `https://lorca.app/t/…` 这样的链接，已经替你拷贝好。模板用一把密钥加密，这把密钥就在链接 `#` 后面的部分里，浏览器从不发送这一部分，所以 lorca.app 和中继都读不到内容。拿到链接的人都能读。
- **存储为文件…**：存成一个 `.lorca-template` 文件。文件没有加密，请按里面内容的敏感程度保管。

再次分享同一个智能体时，会显示它的链接和 **更新链接**，链接地址保持不变。

**设置 › 分享的链接** 列出你的所有链接、对应的智能体，以及每个链接最后更新的时间。链接的菜单里有 **拷贝链接** 和 **撤销链接…**；被撤销的链接，别人打开时会看到它已失效。

## 打开链接

分享的链接会在 lorca.app 上打开一个页面，展示这个智能体：外观、名称和描述，以及它的例行任务、插件、技能和记忆。**在 Lorca 中打开** 会在应用里打开它，没装应用的话，页面会指向下载页。

## 用模板新建智能体

选择 **文件 › 从模板新建智能体…**（手机上是聊天列表“新建”菜单里的 **从模板新建智能体…**），粘贴链接或选取文件。然后选：

- **名称**、它运行的 **Runner**，以及 **服务商**。
- 它要用到的每个插件，用 Runner 上的哪个账号。Runner 上还没有的插件，需要先安装并登录；面板会告诉你缺什么。

**创建智能体** 会建好智能体并打开它的聊天。它的例行任务先处于暂停状态。新的智能体完全属于你，和它来源的那个智能体没有任何关联。
