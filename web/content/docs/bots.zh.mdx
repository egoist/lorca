一个智能体就是一位只做一件事的队友。它有名字、一段说明它如何工作的描述、模型、自己的[记忆](/zh/docs/memory)，还有一个 **Runner**：它工作所在的电脑。每个智能体都有一个和你的单聊，也可以加入[群聊](/zh/docs/group-chats)。

## 创建智能体

在标题栏的 Create 按钮里选择 **新建智能体…**（或 **文件 › 新建智能体…**），然后填写：

| 字段 | 含义 |
| --- | --- |
| **名称** | 你怎么称呼它，也是你在 `@` 后面输入的名字。 |
| **描述** | 它做什么以及应该如何工作：职责、标准、语气、限制和要避免的事。其他智能体靠这段话判断一件工作该交给谁。 |
| **Runner** | 它运行所在的电脑。任何运行 macOS、Linux 或 Windows 的已配对设备。 |
| **服务商** 和 **模型** | 它使用哪个 AI 账号和模型。Model 留在 Default 就跟随服务商的默认模型。 |
| **思考** | 模型在回答前思考多少，从 off 到 max。 |

你也可以让智能体来做。幕僚长或任何智能体都能替你创建队友：“创建一个审查我 pull request 的智能体。”新智能体会带着自己的聊天出现在侧边栏。在群聊里创建的智能体会加入那个群。

## 从市场添加智能体

市场里有现成的智能体：晨间简报、研究员、pull request 审查员、网页守望者等等。打开市场（侧边栏右下角的四个圆点），选一个智能体查看它的指令、例行任务和它配合使用的插件，然后点按 **添加**。

智能体会在市场顶部显示的 Runner 上开始工作，它的聊天以你的问候开场。在第一次回复里，它会：

- 把它应该已经知道的事存进记忆；
- 问你是否开启它的例行任务，这些任务先处于暂停状态；
- 为 Runner 上还没有的每个插件发一张卡片，经你允许后再安装。

之后它和其他智能体一样：可以编辑、改名或删除。

## 编辑智能体

打开智能体的聊天，切换出检查器（inspector）。在那里可以修改它的资料、它 **运行方式** 的模型、它的[例行任务](/zh/docs/routines)、[插件](/zh/docs/plugins)和[记忆](/zh/docs/memory)。修改从智能体的下一轮开始生效。

点击检查器里的头像打开 **外观**：选一个符号和一种强调色，或者用你自己的图片。外观会同步到你所有的设备。

智能体之间也能互相编辑。“幕僚长，让 Scout 的回复短一点”会修改 Scout 的描述。

## 智能体在哪里运行

一个智能体只在一个 Runner 上运行。它的文件、shell 命令、插件和记忆都在那台电脑上。如果 Runner 在睡眠或离线，你的消息会在中继上等着，Runner 回来后智能体再回答。

你可以从任何设备（包括手机）为你的任何一个 Runner 创建智能体。

## 工作目录

每个智能体在它的 Runner 上都有一个工作目录。文件工具和 shell 工具里的相对路径都从那里解析。默认是 Lorca 为这个智能体建的文件夹；如果智能体的工作就是某个项目，把它指向那个项目的文件夹。

## 上下文与花费

检查器会显示智能体的上下文窗口用了多少（“Context 128k of 1M · 13%”），以及这个聊天花了多少（“Spent $0.42 · 18 turns”）。对于 ChatGPT 和 Grok 订阅，这个数字是按 API 价格折算的花费；你并不按 token 付费。

长聊天会自己压缩：当聊天接近模型的窗口上限时，较早的部分会被总结，最近的消息保持原样。在那之前，智能体会把值得长期保留的内容存进记忆。检查器里的 **压缩** 可以手动触发。
