手机应用是你账户下一台完整的设备：同样的密钥，同样的聊天，同样的端到端加密。智能体仍然运行在你的电脑上；手机通过中继和它们通信。

## 安装应用

- **iPhone 和 iPad：**在[下载页面](/zh/download)通过 TestFlight 加入测试。
- **Android：**在[下载页面](/zh/download)下载 APK 并打开。Android 会请你允许浏览器安装应用；Lorca 第一次自动更新时，也会请你允许 Lorca 安装应用。应用每天检查一次新版本并提示安装，**设置 › 更新**可以立即检查。需要 Android 7.0 或更高版本。

## 配对手机

在桌面应用中选择 **配对设备…**，然后用手机应用扫描二维码。也可以粘贴桌面应用或任意已有身份的电脑运行 `lorca pair` 后给出的配对字符串，或者把它当作 `lorca://pair` 链接打开。配对需要一个手机能访问的[中继](/zh/docs/relay)。

## 你能做什么

- 和任何智能体或群**聊天**。智能体边写，回复边在手机上变长。
- **添加**照片、拍摄的照片和文件作为附件。
- **听写**消息。长按麦克风切换语言。
- 为你的任何一个 Runner **创建智能体**、发起群聊，并在智能体的详细信息里更改名称、描述、服务商、模型、思考级别、[访问权限](/zh/docs/access)和[上限](/zh/docs/limits)。
- **回答卡片：**权限卡片、插件登录（登录页在手机上打开）、用 **填写** 回答[密钥](/zh/docs/secrets)请求、命令提出的问题，以及[编程智能体](/zh/docs/coding-agents)的提问。
- **发送草稿：**修改、发送或舍弃智能体的邮件和 Slack [草稿](/zh/docs/reviews)，并在详细信息里批准等待审核的内容。
- **跟进工作：**聊天的详细信息里有[任务](/zh/docs/tasks)、[输出](/zh/docs/chats#输出)、群聊的[项目](/zh/docs/group-chats#项目)、例行任务和它们的运行状况，以及[频道](/zh/docs/channels)。聊天列表里的[关注事项](/zh/docs/attention)按钮会显示需要你处理的事。
- **教会智能体：**编写[技能](/zh/docs/skills)，或用 **添加技能 › 从这个聊天中…** 存一个；给出[反馈](/zh/docs/feedback)，接受建议的修改。
- **分享智能体：**详细信息里的 **作为模板分享**、“新建”菜单里的 **从模板新建智能体…**，以及 **设置 › 分享的链接**。见[分享智能体](/zh/docs/templates)。
- 用“新建”菜单里的 **新建工作流** 设置[工作流](/zh/docs/workflows)。
- **整理聊天：**分组、隐藏和静音。见[聊天](/zh/docs/chats#整理聊天)。
- **管理例行任务：**在聊天详情里暂停、恢复、立即运行或删除。
- 在 Runner 上**安装插件**、登录插件账号、设置调用上限、管理智能体的[浏览器配置文件](/zh/docs/browser)，以及编辑[自动审查](/zh/docs/auto-review)规则。添加新账号要在电脑上进行。
- 使用 API 密钥或订阅登录来**接入服务商**。凭据会加密同步到每一台已配对的设备。
- **配对和取消配对**设备，以及更新 Runner 上的命令行。

智能体工作时再发一条消息，就会调整它的方向。当前这一步模型调用和工具会先完成，然后新指令会加入同一轮。手机可以从 **正在运行的任务** 里一次停止一条命令；停止整轮工作的[停止](/zh/docs/chats#停止)按钮和智能体记忆编辑器在桌面应用中提供。

## 通知

智能体完成回复，或者用卡片问你问题时，手机会收到一条推送，带着智能体的名字和它所说内容的开头。内容在 Runner 上加密，在你的手机上解开。Apple、Google 和中继只看得到“New reply”。

点击通知打开对应的聊天。你正在看的聊天，以及你正在某台电脑上看着的聊天，都不会弹出横幅；打开一个聊天会清除它的通知。[静音的聊天](/zh/docs/chats#静音聊天)不会发通知。
