手机应用是你账户下一台完整的设备：同样的密钥，同样的聊天，同样的端到端加密。智能体仍然运行在你的电脑上；手机通过中继和它们通信。

## 配对手机

在 Mac 上选择 **配对设备…**，然后用手机应用扫描二维码。也可以粘贴配对字符串，或者把它当作 `lorca://pair` 链接打开。配对需要一个手机能访问的[中继](/zh/docs/relay)。

## 你能做什么

- 和任何智能体或群**聊天**。智能体边写，回复边在手机上变长。
- **添加**照片、拍摄的照片和文件作为附件。
- **听写**消息。长按麦克风切换语言。
- 为你的任何一个 Runner **创建智能体**、发起群聊，并在智能体详情中更改服务商、模型或思考级别。
- **回答权限卡片**和[插件](/zh/docs/plugins)的登录卡片。
- **管理例行任务：**在聊天详情里暂停、恢复、立即运行或删除。
- 在 Runner 上**安装插件**，编辑 [自动审查](/zh/docs/auto-review) 规则。
- 使用 API 密钥或订阅登录来**接入服务商**。凭据会加密同步到每一台已配对的设备。
- **配对和取消配对**设备。

智能体工作时再发一条消息，就会调整它的方向。当前这一步模型调用和工具会先完成，然后新指令会加入同一轮。单独的立即 **停止响应** 按钮和智能体记忆编辑器只在 Mac 上提供。

## 通知

智能体完成回复时，手机会收到一条推送，带着智能体的名字和它所说内容的开头。内容在 Runner 上加密，在你的手机上解开。Apple、Google 和中继只看得到“New reply”。

点击通知打开对应的聊天。你正在看的聊天不会弹出横幅，打开一个聊天会清除它的通知。
