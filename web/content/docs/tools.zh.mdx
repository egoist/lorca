智能体在它的 Runner 上工作，用的是 AI 编程助手标配的那类工具。它**以你的身份**运行，拥有你这个用户的权限，就在你指定的那台电脑上。

## 在电脑上

| 工具 | 智能体用它做什么 |
| --- | --- |
| **Read、write、edit** | 打开、新建和修改文件。 |
| **Grep、find、ls** | 动手之前，先找到那一行、那个文件、那个目录。它们会遵守 `.gitignore`。 |
| **Shell** | 运行命令：构建、测试、git、脚本。**停止响应** 会终止正在运行的命令。 |

相对路径从智能体的[工作目录](/zh/docs/bots#工作目录)解析。

命令看到的 `PATH` 和环境变量与你的终端相同。在 Mac 或 Linux 上，Lorca 启动时会从你的登录 shell（zsh、bash 或 fish）读取它们，所以即使 Lorca 是由应用启动的，`npm`、`cargo` 和 `brew` 也照样能用。插件服务器也会得到这些变量。修改 shell 配置后，请重启 Lorca。

<Callout type="warn" title="智能体拥有你的权限">
  Shell 命令以你的用户身份运行，并不局限于工作目录。它可以控制文件、进程、凭据、应用和网络。在智能体的描述里写下与你对自己运行的脚本的信任程度相符的限制；把智能体分配到一台你放心让它控制的机器上。
</Callout>

Shell 命令开始前，Lorca 会解析它的全部阶段，并把完整命令交给[自动审查](/zh/docs/auto-review)。安全的工作会自动运行；有风险的工作，命令的卡片会先征求你的同意。被允许的命令保留你的用户所拥有的全部访问权限。

## 命令卡片

智能体运行的每条命令，从开始到结束都在聊天里显示为同一张卡片：自动审查检查它时，它征求你的许可时（**允许一次**、**始终允许**或**拒绝**），它运行时显示最新的输出，结束后变成一行，说明它是如何结束的。点按命令可以查看完整内容。

## 命令需要输入时

每条命令都在它自己的终端里运行，所以 `sudo`、`ssh`、密钥的口令或 `[Y/n]` 都可以向你提问。命令停在一个问题上，或者 20 秒没有任何输出时，不会拖住智能体：它的回合照常继续，智能体回答它知道的。其余的交给你，在命令的卡片上完成。

- 在任意一台设备上，从卡片里**回答**。你输入的内容直接发送给命令，不会保存在聊天中；终端也不会回显它，所以智能体读不到。智能体会把密码和一次性验证码留给你来输入。命令结束后，智能体会得知结果并继续工作。
- 从卡片里**停止**，或者用聊天里的**停止响应**。

智能体向命令输入的任何内容，都会像新命令一样先经过[自动审查](/zh/docs/auto-review)。仍在等待的命令会在 30 分钟没有输出、Lorca 退出或所在聊天被删除时自动停止。在 Windows 上，命令无法接收输入。

## 在网络上

答案不在磁盘上的时候，DeepSeek、Anthropic、ChatGPT 和 Grok 智能体会搜索网络、阅读网页。搜索在服务商一侧运行，无需任何设置。Grok 智能体还能搜索 X。

## 与团队一起

| 工具 | 作用 |
| --- | --- |
| **给智能体发消息** | 把工作交给当前聊天之外的智能体。参见[聊天](/zh/docs/chats#智能体之间互相发消息)。 |
| **列出队友** | 查看每个智能体、它的职责、它的 Runner，以及那个 Runner 是否在线。 |
| **创建和编辑智能体** | 组建团队：新建一位队友，或者修改某位队友的描述、模型或工作目录。 |
| **例行任务** | 为自己安排周期性的工作。参见[例行任务](/zh/docs/routines)。 |
| **记忆** | 保存和回忆它学到的东西。参见[记忆](/zh/docs/memory)。 |
| **插件** | 在市场里搜索插件，请求安装插件，请你登录。参见[插件](/zh/docs/plugins)。 |

## 插件工具

Runner 上安装的每个[插件](/zh/docs/plugins)都会让那里的智能体发现其工具：创建 GitHub issue、读取 Linear 工单、操作浏览器。只有任务需要时，Lorca 才加载匹配的工具结构。会改动东西的操作要先经过 [自动审查](/zh/docs/auto-review)。
