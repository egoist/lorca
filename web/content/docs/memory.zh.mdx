每个智能体都能跨聊天记住事情。它的记忆是它的 Runner 上的一个 Markdown 文件夹。除非你从另一台设备打开，这些文件不会离开那台电脑；即使离开，也是加密传输。

## 智能体保存什么

- **精选记忆**（`MEMORY.md`）：智能体认为值得保留的、带日期的事实。“用户喜欢简短的回复。”“发票每月 1 号寄出。”这个文件的开头部分在每一轮都摆在智能体面前。
- **专题笔记**：较长的笔记，智能体需要时才打开。
- **每日日志**：一本流水账，记录发生了什么：每完成一轮记一行，外加智能体自己添加的事件。日志只被搜索，从不整个加载。

事实发生变化时，智能体会把旧条目划掉并添加新条目，所以文件里看得出什么变了、什么时候变的。

任何看起来像凭据的东西，比如 API 密钥、令牌、密码，在写入之前都会被抹掉。

## 回忆

智能体可以按关键词和时间搜索它的记忆和它所在的每一个聊天：“上周我们关于定价是怎么决定的？”每一轮开始时，它还知道过去两天里自己在其他每个聊天里最后说过什么，所以群里的智能体知道一小时前它在单聊里做了什么。

## 让智能体记住

直接说就行：“记住，预发布环境的部署需要工单。”让它忘记、让它更正也是一样。

在长聊天被[压缩](/zh/docs/bots#上下文与花费)之前，智能体会悄悄把那些只在对话里说过、值得长期保留的内容存下来。

## 阅读和编辑记忆

打开智能体的聊天，切换出检查器，找到 **记忆**。你可以阅读精选记忆，查看它占用了多少加载预算，编辑它，并在 Finder 里打开文件夹。如果你编辑时智能体改动了文件，Lorca 会显示它的版本，并问你是重新加载还是覆盖。

对运行在另一个 Runner 上的智能体也一样可以，只要那个 Runner 在线。
