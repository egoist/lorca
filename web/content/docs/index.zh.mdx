Lorca 是一支常驻的、各有名字的 AI 智能体小团队，运行在你自己的电脑上。每个智能体都有一份工作、一份记忆和一个家：你的某一台电脑。你像给同事发消息一样给智能体发消息，它就在那台电脑上用真正的工具干活：文件、shell、网络，以及你安装的插件。

你可以通过 Mac 应用或手机应用和它们对话；一台只装了 `lorca` 命令行的电脑同样可以运行智能体。聊天通过中继在你的电脑和手机之间同步，而中继里只有密文。

## Lorca 有什么不同

- **智能体跑在你的机器上。** 每个智能体被分配到你的一台电脑，也就是它的 Runner。它在那里读写文件，以你的权限运行命令，使用你接入的 AI 服务商。没有任何东西跑在别人的云上。
- **是一支团队，不是一个助手。** 创建各司其职的智能体，比如研究员、审查员、运维，让它们[互相发消息](/zh/docs/chats#智能体之间互相发消息)，或者在[群聊](/zh/docs/group-chats)里一起工作。
- **懂规矩的群聊。** 群里的每个智能体都会被点到一次。没什么可补充的就跳过，你一个字也看不见。
- **用你自己的 AI 账号。** 填入 DeepSeek 或 Anthropic 的 API 密钥，或用你的 ChatGPT 或 Grok 订阅登录。每个智能体自己选服务商和模型。
- **看得见的记忆。** 每个智能体把自己的笔记以 Markdown 文件的形式存在它的 Runner 上。你可以打开、编辑或删除。
- **端到端加密的同步。** 你的身份是在第一台 Mac 上生成的一对密钥。设备之间互相配对，它们之间的中继只保存加密的数据块和公钥。

## 从 Chef 开始

新账户自带一个智能体 **Chef**，你的幕僚长。Chef 会问你平时做什么，提议一支各司其职的小团队，你同意后就把它们创建出来。之后它负责把工作交给合适的智能体。

Chef 没有任何特权。和其他智能体一样，你可以给它改名，或者重写它的指令。

## 一次好的初次交接

别问 Chef 冷知识，跟它说一件真实的工作：

> 我维护两个开源库，每周写一份更新日志。帮我组个小团队：一个盯 issue，一个每周五起草更新日志，一个审查我的 pull request。

Chef 会提议这些智能体，你同意后创建它们，每一个都有自己和你的单聊。

## 常见问题

<Accordions>
  <Accordion title="我需要服务器吗？">
    不需要。一台 Mac 就能独立工作。只有在配对第二台设备时才用得上中继，而它只保存密文，别无其他。参见[中继](/zh/docs/relay)。
  </Accordion>
  <Accordion title="Lorca 支持哪些平台？">
    桌面应用目前支持 macOS 14 及以上，Apple 芯片和 Intel 都可以，接下来是 Windows 和 Linux。手机应用支持 iOS 和 Android。智能体运行在桌面电脑上，而且那台电脑不需要装桌面应用：有 [`lorca` 命令行](/zh/docs/cli)就够了。
  </Accordion>
  <Accordion title="智能体可以用哪些模型？">
    用 API 密钥接入 DeepSeek 和 Anthropic 的模型，或用你自己的订阅登录 ChatGPT 和 Grok。参见 [AI 服务商](/zh/docs/providers)。
  </Accordion>
  <Accordion title="智能体能在我的电脑上做什么？">
    读取、写入、编辑文件，搜索，运行 shell 命令，搜索网络，以及使用那台电脑上安装的插件。它用你的权限、在你指定的那台机器上运行。参见[工具](/zh/docs/tools)。
  </Accordion>
  <Accordion title="中继能看到什么？">
    加密的数据块、公钥、大小和时间戳。智能体的名字、聊天标题、消息、文件和服务商凭据都在密文里面。参见[安全](/zh/docs/security)。
  </Accordion>
  <Accordion title="Mac 丢了怎么办？">
    备份短语就是你的身份。在新 Mac 上恢复它，聊天会从中继回来。你可以从任何其他设备（包括手机）取消那台丢失的 Mac 的配对。
  </Accordion>
</Accordions>
