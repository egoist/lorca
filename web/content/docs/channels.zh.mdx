**频道** 让智能体通过一个 Telegram 或 Slack 账号接收消息：在你允许的群和聊天里，接收每条消息、提到它或回复它的消息，或者带某个话题标签（比如 #feedback）的消息。每接到一条消息，智能体就按频道的任务开始工作，并以这个账号自己的机器人身份在原帖里回复，绝不会冒充你。

Telegram 和 Slack 由你的 Runner 直接读取，不需要公网地址，也不需要你自己的服务器。

## 接入账号

账号要在电脑上添加，在[市场](/zh/docs/plugins#市场)或 **设置 › 插件** 里。一台 Runner 可以有多个账号，各有各的名字。

- **Telegram：** 用 [BotFather](https://t.me/BotFather) 新建一个机器人（`/newbot`），添加一个 **Telegram** 账号，粘贴机器人的 token。在群里，Telegram 机器人默认只能收到回复和命令，除非它是管理员，或者关掉了隐私模式（在 BotFather 里用 `/setprivacy`，然后把它重新拉进群）。如果这一点挡了路，频道的面板里会提示。
- **Slack：** 用你登录的那个 [Slack 账号](/zh/docs/plugins#多个账号)，它的 Slack 应用要有一个机器人用户，并打开 Socket Mode。设置里填入应用的 Bot User OAuth Token（`xoxb-…`）和一个应用级 token（`xapp-…`）；输入框会列出应用需要的权限范围和事件。

然后把机器人拉进 Telegram 群，或邀请它进 Slack 频道。这个聊天会请求允许，你允许之后机器人才会在那里回复（见[谁能找到机器人](#谁能找到机器人)）。

## 设置频道

对智能体说：

> 在 Acme Community 这个 Telegram 群里，接收提到你的消息、回复你的消息和带 #feedback 的消息。每条都在 GitHub 上建一个 issue，并用 issue 编号感谢对方。

智能体会把频道设置好：用哪个账号、接收哪些消息、任务是什么，以及在哪些聊天里回复。之后它单聊的检查器里，例行任务下面会出现 **频道** 部分（手机上在详细信息里）：每个频道写着它接收什么，并有一个暂停开关。

## 对话

每个 Telegram 群或话题、每个 Slack 帖子，都是聊天列表里的一个 **对话**，以它的标题显示，配上智能体的头像，例如“Feedback Collector · Telegram”。里面按名字显示那里的人和智能体的回复，这些回复不会标为未读。你也可以在对话里发言：智能体会在 Lorca 里回答你，或者按你的要求在原帖里回复。删除对话只会删除它在 Lorca 里的记录。

对话一开始和智能体单聊在同一个[分组](/zh/docs/chats#整理聊天)里；单聊静音的话，它也是静音的。

## 谁能找到机器人

任何人都能给 Telegram 机器人发消息，或把它拉进自己的群；你 Slack 工作区里的任何人，以及机器人所在的 Slack Connect 频道里的人，也都能给它写消息。所以频道只在你允许的聊天里回复，被允许的聊天里每个人都能找到它。

有人把机器人拉进群，或者一个你没允许的聊天发来频道本会接收的消息时，这个聊天会 **请求对话**：频道那一行显示 **有聊天等待允许**，频道面板的 **请求对话** 下会列出它，以及是谁发的消息或拉的机器人。**允许** 之后，机器人从此在那里回复，先处理聊天等待期间别人问它的内容；**忽略** 之后，这个聊天不会再来请求。在你允许之前，机器人在那里什么也不做：第一个给它写消息的人会收到一条“Pending approval”回复，之后不会再有。想自己给机器人发消息，先发一条，再把这个聊天也允许。

如果某个聊天一直没来请求，比如机器人在一个群里只能收到回复它的消息，可以在面板 **聊天** 那一行点 **添加…**，粘贴聊天的 ID，Telegram 群聊的 ID 形如 `-1001234567890`。

你也可以直接对智能体说：“在反馈频道里允许 Acme Beta Testers。”外面来的消息不能允许聊天，因为只有你自己的消息能修改频道。

## 别人能做什么、不能做什么

智能体只读取人们发的文字，以及他们在 Telegram 发的图片（有配文或没配文都行），不理会其他机器人的消息、编辑、入群提示，也不理会频道开始接收之前发的消息。别人写的内容只是供智能体参考的信息，绝不是指令：它不能批准任何操作，不能修改智能体的设置，也不能开启别的频道。智能体的回复要经过它的[访问权限](/zh/docs/access)、[自动审查](/zh/docs/auto-review)和这个账号的[调用上限](/zh/docs/limits#插件调用上限)，也永远不会带出[密钥](/zh/docs/secrets)。

## 消息卡住时

如果智能体处理某条消息时失败或被打断，后面的消息会排队等待。频道显示 **待处理**，[关注事项](/zh/docs/attention)里也会列出它，频道的面板里有 **重试** 和 **跳过**。在对话里按 **停止** 会结束对这条消息的处理，频道接着处理下一条。开关可以暂停频道：暂停期间到达的消息不会被接收。

点一个频道打开它的面板：**接收消息** 开关、当前状态、账号、群聊、接收哪些消息、请求对话的聊天、任务、最近的对话，以及 **移除…**，移除后对话仍会保留。

## 反馈收集

**Feedback collector**（反馈收集）[工作流](/zh/docs/workflows)一次把这些都设置好：一个 Telegram 账号和 GitHub、要用的仓库、Feedback Collector 智能体、每天早上的汇总，以及一个接收提及、回复和 #feedback 的频道——它会新建或更新 issue，并在原帖里感谢对方。它的示例会起草一份汇总和一条回复；你开启工作流时，频道就开始接收消息。这时把机器人拉进你的群，等群来请求时允许它。
