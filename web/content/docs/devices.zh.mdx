你配对的每一台 Mac、PC 或手机都是一台**设备**。运行桌面操作系统（macOS、Linux 或 Windows）的设备同时也是 **Runner**：可以把智能体分配给它。手机和平板持有你的密钥和聊天，但从不运行智能体。

| | Runner（macOS、Linux、Windows） | 手机或平板 |
| --- | --- | --- |
| 读写聊天 | 可以 | 可以 |
| 创建智能体、配对设备 | 可以 | 可以 |
| 运行智能体、插件和例行任务 | 可以 | 不可以 |

## 配对设备

配对需要一个两台设备都能访问的[中继](/zh/docs/relay)。先在 **设置 › 高级 › 中继 URL** 里设置好。

<Steps>
<Step>

### 显示配对码

在一台已经设置好的设备上，选择 **文件 › 配对设备…**（⇧⌘P），或者 Settings 里设备下拉菜单底部的 **配对设备**。Lorca 会显示一个二维码和一串配对字符串，十分钟内有效。

</Step>
<Step>

### 在新设备上输入

在新 Mac 上，引导流程里选择 **配对** 并粘贴字符串。在手机上，扫描二维码。在只有命令行的电脑上：

```bash
lorca pair 'lorca://pair?…'
```

</Step>
<Step>

### 等待同步

新设备先收到你的账户密钥，然后是智能体、服务商凭据和聊天。凭据一到，Runner 就可以运行智能体了。

</Step>
</Steps>

配对面板上的 **取消** 会让配对码立即失效。

## 管理设备

**设置 › 设备** 显示每台设备的角色、最后在线时间和机器密钥。**设置 › 智能体** 和 **设置 › 插件** 显示工具栏里选中的那台设备上有什么。

## 取消配对

任何设备都可以取消任何其他设备的配对，所以你可以用手机移除一台丢失的 Mac。被取消配对的设备会被中继永久拒绝，它下次运行时会删除自己的密钥、凭据和聊天。再次配对会给它一把新的密钥。

要让一台设备自己退出，在它自己的 Devices 面板里取消配对。

## 在新 Mac 上恢复

引导流程里选择 **恢复** 并输入备份短语。Lorca 会重建你的密钥，并从中继拉回你的账户。原来运行在旧 Mac 上的智能体需要一个新的 Runner；它们的记忆和工作文件留在了旧磁盘上。
