---
title: 快速开始
description: 设置 Lorca，创建身份，接入 AI 服务商，发出第一条消息。
icon: Rocket
---

你需要一个受支持的 AI 账号：API 密钥，或者 ChatGPT 或 Grok 的订阅。本指南使用桌面应用，支持 Mac、Windows 和 Linux。要在没有桌面应用的电脑上设置，请看[命令行](/zh/docs/cli)。

<Steps>
<Step>

### 安装应用

[下载适合你电脑的 Lorca](/zh/download)：

- **Mac：** 打开下载的 `.dmg` 文件，把 Lorca 拖进“应用程序”目录。
- **Windows：** 运行安装程序。智能体用 [Git for Windows](https://git-scm.com/downloads/win) 自带的 bash 运行命令，请一并安装。
- **Linux：** 运行下载页上的安装命令。它把 Lorca 安装到你的主目录，不需要 root。也可以用 Debian 软件包，它在你安装下一个软件包时更新。

应用会自动更新。在 Mac 上，Lorca 菜单里有 **检查更新…**；在 Windows 和 Linux 上，它在 **文件** 和 **帮助** 菜单里。

</Step>
<Step>

### 创建身份

首次启动时选择 **新建**。Lorca 会在这台电脑上生成一对密钥，并显示**备份短语**：十三组、每组四个字符。

<Callout type="warn" title="把短语抄下来">
  备份短语就是你的身份。它是在另一台电脑上恢复账户的唯一办法，没有人能替你重置。把它离线保存在安全的地方。
</Callout>

如果你已经有账户，选择 **恢复** 并输入短语，或者选择 **配对**，粘贴来自另一台已设置好电脑的配对字符串。另一台电脑可以在桌面应用中选择 **配对设备**，或在终端中运行 `lorca pair` 来显示字符串。

</Step>
<Step>

### 给第一个智能体起名

每个账户都从一个名叫“幕僚长”的智能体开始。保留这个名字，或者换一个你喜欢的。

</Step>
<Step>

### 接入服务商

粘贴 DeepSeek、Anthropic、OpenCode Zen 或 OpenCode Go 的 API 密钥，或者登录 ChatGPT 或 Grok。登录会在浏览器里打开。这一步可以跳过，之后在 **设置 › 服务商** 里接入，但在接入至少一个服务商之前，智能体无法回答。

</Step>
<Step>

### 和幕僚长打个招呼

打开幕僚长的聊天，说说你的工作。幕僚长会提议一支团队，你同意后就创建。按 Return（Windows 和 Linux 上是 Enter）发送；`+` 按钮添加附件，在 Mac 上还可以用麦克风听写。

</Step>
</Steps>
