---
title: 快速开始
description: 在 Mac 上安装 Lorca，创建身份，接入 AI 服务商，发出第一条消息。
icon: Rocket
---

你需要一个 AI 账号：DeepSeek 或 Anthropic 的 API 密钥，或者 ChatGPT 或 Grok 的订阅。本指南使用桌面应用，目前支持 macOS 14 及以上。要在没有桌面应用的电脑上设置，请看[命令行](/zh/docs/cli)。

<Steps>
<Step>

### 安装应用

[下载 Lorca Mac 版](/download)，打开磁盘映像，把 Lorca 拖进“应用程序”。应用会自动更新；Lorca 菜单里有 **检查更新…**。

</Step>
<Step>

### 创建身份

首次启动时选择 **新建**。Lorca 会在这台 Mac 上生成一对密钥，并显示**备份短语**：十三组、每组四个字符。

<Callout type="warn" title="把短语抄下来">
  备份短语就是你的身份。它是在新 Mac 上恢复账户的唯一办法，没有人能替你重置。把它离线保存在安全的地方。
</Callout>

如果你已经有账户，选择 **恢复** 并输入短语，或者选择 **配对**，粘贴来自一台已设置好的 Mac 的配对字符串。

</Step>
<Step>

### 给第一个智能体起名

每个账户都从一个智能体 Chef 开始。保留这个名字，或者换一个你喜欢的。

</Step>
<Step>

### 接入服务商

粘贴 DeepSeek 或 Anthropic 的 API 密钥，或者登录 ChatGPT 或 Grok。登录会在浏览器里打开。这一步可以跳过，之后在 **设置 › 服务商** 里接入，但在接入至少一个服务商之前，智能体无法回答。

</Step>
<Step>

### 和 Chef 打个招呼

打开 Chef 的聊天，说说你的工作。Chef 会提议一支团队，你同意后就创建。按 Return 发送；`+` 按钮添加附件，麦克风用来听写。

</Step>
</Steps>

## 接下来做什么

- 用标题栏里的 **新建智能体…** [自己创建一个智能体](/zh/docs/bots)。
- 拉两三个智能体[开一个群聊](/zh/docs/group-chats)。
- [配对手机或第二台电脑](/zh/docs/devices)。配对需要一个[中继](/zh/docs/relay)。
- [安装插件](/zh/docs/plugins)，比如 GitHub 或 Linear。
