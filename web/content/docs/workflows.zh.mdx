**工作流** 在一个页面里把一件事设置好：回答一两个问题，选定或新建智能体，接入需要的账号，再运行一次 **示例** 给你看。只有你点头，它的时间安排才会开启。

| 工作流 | 做什么 | 账号 |
| --- | --- | --- |
| **Meeting preparation**（会议准备） | 工作日早上为接下来的会议准备简报和议程。 | Google Calendar、Google Drive |
| **Inbox triage**（收件箱整理） | 工作日早上列出需要你处理的邮件，并附上下一步的草稿。 | Gmail |
| **Repository monitoring**（仓库监控） | 工作日早上列出需要你关注的 issue、pull request 和发布。 | GitHub |
| **Feedback collector**（反馈收集） | 把 Telegram 群里的反馈整理成 GitHub issue，每天早上发一份汇总。见[频道](/zh/docs/channels#反馈收集)。 | Telegram、GitHub |

这份列表由市场维护，新的工作流无需更新 Lorca 就会出现。

## 设置一个工作流

打开市场，**工作流** 排在最前面。初次设置的最后一页也有 **选择工作流…**；手机上是聊天列表“新建”菜单里的 **新建工作流**。选一个，它的页面会在顶部显示的 Runner 上进行设置。

1. **初始设置：** 回答它的问题，比如关注哪些仓库、什么算优先，并选定 **智能体**。Lorca 会推荐一个你已有的合适智能体，或者把它将新建的智能体标为“新”。
2. **账号：** 每个服务会显示它的状态，或者它需要的那一个按钮：**添加**、**登录** 或 **设置**。点一行会打开这个账号的面板。在手机上，添加账号要到电脑上进行。
3. **运行示例**：要等每个问题都有答案、每个账号都就绪后才能点。智能体会在它的聊天里按工作流的方式完整做一次，回复显示在页面上。
4. 看完示例后，选 **开启时间安排**，或 **以后再说** 先不开。两者都会打开智能体的聊天，示例就在那里。

工作流的例行任务一开始是暂停的，直到你开启时间安排。之后修改某个回答、换智能体或换账号，都会丢弃这份示例并暂停例行任务，直到你运行新的示例。

## 修改或停用

再次打开工作流，可以看到它的回答、示例和时间安排。**取消设置** 会停止还没完成的设置，并保留你的回答供下次使用；工作流开启后，**关闭工作流** 会暂停它的例行任务。智能体和它的聊天都会保留。工作流之前就属于你的例行任务和智能体，保持原来的状态。
