智能体做到一半需要密码、API 密钥或一次性验证码时，会在聊天里用一张卡片向你要。你在任何一台设备上填好，值会加密送到智能体的 Runner 上，并且只留在那里。它不会进入聊天，不会到你的其他设备，也不会出现在 AI 服务商能看到的内容里：智能体只按名字使用它。

## 回答卡片

卡片会写明谁在要、值用在哪里，比如“Developer 需要 github.com 的密钥”，说明智能体为什么需要，并为每个值提供一个输入框，输入的内容会被隐藏。**保存** 后发出，卡片显示“已保存”和保存的是什么；**以后再说** 则是拒绝。在手机上，轻点 **填写** 打开输入框。

智能体最多等十分钟。如果你改为直接发消息，或者按了 **停止**，这张卡片就会被搁置。[例行任务](/zh/docs/routines)和事件运行时没人能回答，所以它们不能要密钥。

不要把密码直接粘贴到聊天里：消息会同步到每一台设备，也会发给 AI 服务商。智能体也被告知要用卡片来要。

## 密钥用在哪里

智能体要密钥时会说明一个用途，这个密钥也只能用在那里：

- **浏览器里的某个网站：** 在智能体的[浏览器](/zh/docs/browser)里，填进那个网站的登录页，而且只在浏览器停留在那个网站、并使用 HTTPS 时才会填。
- **命令：** 作为环境变量（比如 `NPM_TOKEN`），提供给写明要用它的命令，包括智能体启动的[编程智能体](/zh/docs/coding-agents)。
- **插件的设置：** 插件自己的某个字段，比如它的 API 密钥。

密钥属于要它的那个智能体。同一个名字再要一次会替换旧值；删除智能体会删除它的密钥。智能体换到另一台 Runner 后，需要在那里重新要。

## 不会露出来

无论哪个工具把保存的值回显出来——命令的输出、网页、编程智能体的记录，还是浏览器录制——智能体和你的设备看到的都是密钥的名字，而不是它的值。邮件和 Slack [草稿](/zh/docs/reviews)以及[频道](/zh/docs/channels)的回复里，永远不会带上密钥。

## 管理密钥

**设置 › 密钥** 列出工具栏里所选 Runner 上的密钥：属于哪个智能体、这个值是什么、用在哪里。点一个密钥，可以用 **替换** 填入新值，或者 **删除…** 它。在手机上，设置里某台 Runner 的页面有 **密钥** 部分。新值会加密传到 Runner。

<Callout type="warn" title="Shell 权限能读到它们">
  有 shell 或文件权限的智能体以你的身份运行，而你的用户能读到 Lorca 存在那台电脑上的内容。密钥让值不进入聊天和模型，但挡不住一个能运行任意命令的智能体。如果某个密钥只能让一个智能体碰到，就给这个智能体一台单独的 Runner。
</Callout>
