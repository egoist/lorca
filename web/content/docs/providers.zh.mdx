智能体用你自己的 AI 账号来思考。在任何一台已配对的设备上接入一次服务商，它就会用你的账户密钥加密后送达其他设备。

| 服务商 | 接入方式 | 默认模型 |
| --- | --- | --- |
| **DeepSeek** | API 密钥 | `deepseek-flash` |
| **Anthropic** | API 密钥 | `claude-opus-5` |
| **OpenCode Zen** | API 密钥，按量付费 | `deepseek-v4.1-flash` |
| **OpenCode Go** | API 密钥和 Go 订阅 | `glm-5.3-flash` |
| **ChatGPT** | 用你的 ChatGPT 订阅登录 | `gpt-6.1-sol` |
| **Grok** | 用 SuperGrok 或 X Premium+ 登录 | `grok-4.7` |

DeepSeek、Anthropic、ChatGPT 和 Grok 会在服务商一侧搜索网络。Grok 还能搜索 X。

## 接入

在桌面或手机应用中打开 **设置 › 服务商**，选择一个服务商并点击 **接入**。

- **API 密钥：**粘贴密钥。Lorca 会先向服务商验证，再保存。
- **登录：**浏览器会打开服务商自己的登录页面。Lorca 从不接触你的密码。

在终端里：

```bash
lorca provider set deepseek
lorca provider set anthropic
lorca provider set opencode
lorca provider set opencode-go
lorca provider set chatgpt
lorca provider list
```

### 自定义 API 地址

如果要用代理或兼容的服务器，在接入任何 API 密钥类服务商时填写 **Base URL**。密钥会针对那个地址验证。

## 自定义服务商

任何兼容 OpenAI Chat Completions 或 Responses API，或 Anthropic Messages API 的服务器都可以作为服务商：OpenRouter 这样的网关、其他厂商的 API，或者你网络中的模型服务器，例如 Ollama、LM Studio 或 vLLM。打开 **设置 › 服务商**，选择 **添加服务商…**，再选择服务：OpenAI、OpenRouter、Gemini、Groq、Together AI、Ollama 和 LM Studio 会替你填好 API 和基础 URL，**其他服务器…** 则从空白开始。

- **名称：**应用里显示的名字。
- **API：**OpenAI Chat Completions、OpenAI Responses 或 Anthropic Messages。
- **API 基础 URL：**API 路径所在的根地址，例如 `https://openrouter.ai/api/v1` 或 `http://localhost:11434/v1`。面板会显示 Lorca 实际请求的完整地址。
- **API 密钥：**服务器不需要密钥时留空。
- **模型：**填好服务器信息后，它的模型会连同上下文窗口和能否看图一起列出。勾选智能体可以使用的模型，并选择默认模型。服务器没有列出的模型，可以在搜索框里输入它的 ID 添加。

保存时，Lorca 会再向服务器确认一次，借此验证密钥。自定义服务商会像其他凭据一样同步到你的其他设备，它的智能体在各自分配到的 Runner 上运行，所以你网络中的模型服务器要能从那台 Runner 访问。花费显示为 $0，因为 Lorca 不知道服务器的收费。

在终端里：

```bash
lorca provider add "OpenRouter" https://openrouter.ai/api/v1 --model anthropic/claude-sonnet-5 --api-key-stdin
lorca provider add "Ollama" http://localhost:11434/v1
lorca provider add "Claude proxy" https://proxy.example.com/v1 --api messages --model claude-opus-5 --api-key-stdin
```

### 决策 API

决策模型用概率回答带类型的问题，而不写文字。[自动审查](/zh/docs/auto-review#审查模型)可以使用它，智能体不能。在 **添加服务商…** 里选 **OpenRouter Decisions**、**OpenAI Decisions** 或 **TypeSafe** 会替你填好；选 **其他服务器…** 时，API 选择：

- **System One：**TypeSafe 的 API，OpenRouter、OpenCode Zen 和 LLM Gateway 也提供。
- **OpenAI Decisions：**OpenAI 的 Decisions API，Vercel 的 AI Gateway 也提供。

这两种 API 的 URL 就是端点本身，例如 `https://openrouter.ai/api/alpha/decisions`；不带端点路径的 URL 会加上该 API 常用的路径（`/systemone` 或 `/decisions`）。模型列表会列出服务器的决策模型。决策服务商不会出现在智能体的服务商选择器里；在 **设置 › 自动审查** 里选择它，在 **审查模型** 里选择它的模型。

```bash
lorca provider add "TypeSafe" https://api.typesafe.ai/v1/systemone --api system-one --api-key-stdin
```

### 审查模型

**设置 › 服务商 › 审查模型** 里是每个已接入服务商的审查模型，也就是[自动审查](/zh/docs/auto-review#审查模型)在它上面运行的模型。默认是一款小型快速模型；你可以改选这个服务商的任意模型，包括决策模型。

## 为每个智能体选模型

每个智能体在 New Bot 面板、桌面应用检查器的 **运行方式** 下，或手机的智能体详情中选择自己的服务商、模型和思考级别。没有指定模型的智能体使用服务商的默认模型。

如果智能体的服务商没有接入，它的这一轮会以一条提示结束，告诉你去 Settings 里接入。

## 断开

**断开** 会从每一台设备上移除这份凭据。对 Grok 来说，还会撤销登录。**删除** 会从每一台设备上移除一个自定义服务商；在终端里用 `lorca provider remove` 加上 `lorca provider list` 显示的标识（例如 `custom:openrouter`）也一样。

## 花费

DeepSeek、Anthropic 和 OpenCode Zen 按用量计费；OpenCode Go 的用量计入订阅限额。检查器会显示每个聊天花了多少。ChatGPT 和 Grok 登录用的是你的订阅，显示的数字是按 API 价格折算的花费。
