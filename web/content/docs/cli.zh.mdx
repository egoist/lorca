`lorca` 才是真正干活的程序：它持有你的密钥，和中继、AI 服务商通信，并运行智能体。桌面应用内置了它，并替你启动。在没有桌面应用的电脑上，自己运行它，那台电脑就是一个 Runner。

可执行文件在应用内部：`Lorca.app/Contents/Resources/bin/lorca`。

## 命令

| 命令 | 作用 |
| --- | --- |
| `lorca serve` | 运行服务。不带命令时的默认行为。 |
| `lorca identity new` | 创建身份并打印备份短语。 |
| `lorca identity restore <phrase>` | 用备份短语恢复身份。 |
| `lorca identity show` | 显示这台设备的身份。 |
| `lorca pair` | 显示配对字符串，并等待另一台设备。 |
| `lorca pair <string>` | 用配对字符串加入一个账户。 |
| `lorca provider set <kind> [api-key]` | 接入 `deepseek`、`anthropic`、`opencode`、`opencode-go`、`chatgpt` 或 `grok`。省略密钥时从标准输入读取；`--base-url` 设置自定义地址。 |
| `lorca provider remove <kind>` | 在每台设备上断开一个服务商。 |
| `lorca provider list` | 列出已接入的服务商。 |
| `lorca status` | 以 JSON 打印这台设备的状态：设备、智能体、聊天、服务商。 |
| `lorca doctor` | 检查主目录、身份、端口和中继，并指出哪里有问题。 |

## 无屏幕的 Runner

```bash
export LORCA_RELAY_URL=https://relay.example.com
lorca pair 'lorca://pair?…'   # 来自 Mac 上 Pair a Device… 的字符串
lorca serve
```

这台电脑会出现在你的设备列表里，你可以从 Mac 或手机为它创建智能体。

## 环境变量

| 变量 | 设置什么 |
| --- | --- |
| `LORCA_HOME` | 密钥、凭据和聊天的存放位置。默认 `~/.lorca`。 |
| `LORCA_PORT` | 应用连接的本地端口。默认 `4862`。 |
| `LORCA_RELAY_URL` | 中继地址。 |
| `LORCA_DEEPSEEK_MODEL`、`LORCA_ANTHROPIC_MODEL`、`LORCA_CHATGPT_MODEL`、`LORCA_GROK_MODEL` | 没有指定模型的智能体使用的默认模型。 |

## 文件

一切都在 `~/.lorca/` 下，只有你的用户可读：身份和机器密钥、服务商凭据、设置、聊天、附件、插件，以及每个智能体一个的工作区文件夹（里面有它的记忆）。

应用把服务的日志写到 `~/Library/Logs/Lorca/cli.log`。
